# Credit Wise Loan Prediction System

## Project Description
The Credit Wise Loan Prediction System is a machine learning based project that predicts whether a loan application will be approved or rejected based on customer financial and personal details. The system helps in making accurate and faster loan approval decisions.

---

## Objectives
- To analyze loan applicant data
- To build a machine learning model for loan prediction
- To reduce manual effort in loan approval process

---

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

---

## How to Run the Project
1. Clone the GitHub repository
2. Install required libraries using:
   pip install -r requirements.txt
3. Open Jupyter Notebook
4. Run all cells of `credit-wise-loan-prediction.ipynb`

---

## Output
- Visualization of loan data
- Loan approval prediction (Approved / Rejected)
- Model accuracy evaluation
